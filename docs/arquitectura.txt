Flujo de Datos:
1. Cliente envía solicitud al API Gateway
2. Gateway valida contra Auth Service (JWT)
3. Gateway enruta a servicio correspondiente
4. Servicios consultan bases de datos respectivas
5. Respuesta regresa a través del Gateway
6. Eureka mantiene registro de servicios disponibles

Tecnologías:
- Spring Boot 2.7.12
- Spring Cloud (Eureka, Gateway)
- Spring Security
- JWT (JSON Web Tokens)
- MySQL 8.0
- Docker & Docker Compose
